# ラクガキバトル

紙に描いた落書きをカメラで取り込み、色・形・面積を解析してステータスと技セットを生成。
できたオリジナルキャラで **「わざリール」**（オレカバトル風・縦スクロールのスロットを「とめる！」・目押しなし・完全確率）の1対1バトルを戦う、展示向けの Web ゲーム。

設計ノート: https://claude.ai/code/artifact/7f3c4c10-9108-4d6a-888b-02bf1c82f8fa

## 開発

```bash
npm install
npm run dev      # 開発サーバー（空きポートを自動選択、5173+）
npm run build    # 本番ビルド（tsc + vite build、dist/ に PWA 出力）
npm run preview  # ビルド結果をローカル配信
npx vitest       # エンジンのテスト（解析・バトル・相性）
```

## 構成

```
src/
├─ engine/            UI非依存の純粋ロジック（Vitest対象）
│  ├─ analyze/        画像特徴の抽出 → キャラ生成（決定論的：同じ絵 → 同じキャラ）
│  ├─ moves/          約90の技データ（data.ts）＋ 絵の特徴タグでの割り振り（assign.ts）
│  ├─ personalities/  こせい60種（data.ts: パッシブ＋専用アクティブ）＋ 絵でのマッチング（assign.ts）
│  ├─ battle/         わざリール（ring.ts: buildReel/spinReel）・バトル本体（engine.ts）
│  ├─ attributes.ts   属性相性（火→木→水の三すくみ、雷・闇は状態異常特化）
│  ├─ status.ts       状態異常14種（やけど/しびれ/ぬれ/からまり/のろい/どく/こんらん/各種UP・DOWN/ひるみ）
│  ├─ growth.ts       バトル報酬（ステータス強化・属性技進化・新わざ習得）
│  └─ rng.ts          シード付き乱数・画像ハッシュ
├─ scenes/            タイトル / 撮影 / リビール / 相手選択 / バトル / 報酬 / 結果 / 図鑑
├─ store/             Zustand（画面遷移・キャラ・図鑑）
├─ data/              テスト用CPUロスター（雑なダミー4体）
└─ components/         手描きテイストのUI部品
```

## バトル（わざリール・オレカバトル風）

- 毎ターン、**「せめる／ルーレット／こせい」を1タップ**で選ぶ（普段リールは止まっている）
  - **せめる** … リールが回り出す。「**とめる！**」で止める → 窓に来た技が発動
  - **ルーレット** … **こせい**に賭ける運だめし。**約50%で当たり** → こせいが使える状態なら**その場でこせいを無料発動**（クールダウン/回数を消費しない）、こせいが切れていれば**クールダウン/回数を回復**。ハズレは何も起きない。**HP・状態異常には一切作用しない**。当たると3ターンは再度回せない（無料こせい連打の防止）
  - **こせい** … その絵だけの**専用スキル**を発動（クールダウンか回数の制限あり）
- **こせい**：60種以上のパッケージ（常時パッシブ ＋ 専用アクティブ技）から、**解析が絵の特徴で1つ選ぶ**（オフラインで動く・同じ絵は必ず同じこせい）。例：トゲトゲの火の絵 →「ほのおのきば」＝パッシブ「攻撃するたび回復」＋こせい技「ヒートドレイン」
- リールの**7コマ**を引くと、こせい技が**運で無料発動**（クールダウン無視・成功判定あり）
- **技メニューなし**。技は**縦に並んだリールがバトル画面の下で流れている**（別画面に飛ばない・キャラとHPは見えたまま）。中央に赤い**選択窓**
- **目押しではない**：押したタイミングは結果に影響せず、少しスベって**止まる位置は乱数** ＝ 反射神経で差がつかず完全にフェア
- 自分が押したら、まず**自分のリール／行動 → そのあと相手のリール**（すばやさで相手が先に動く場合も、見た目は必ず自分が先。ダメージ計算の順番はエンジン内部で正しく処理）
- 相手のHPが残りわずかだと「とめる！」が「**とどめ！**」になって光る。どちらかがピンチ（HP3割以下）だと画面が赤く脈打つ＋「ピンチ！」表示、**こんじょう**の逆転火力がハッキリ見える
- 各コマに**強さ星（★1〜3）と威力の数字**を表示。★3は金枠・太字で目立つ、★1は小さく地味 ＝ 一目で強弱が分かる。弱い技はコマが多く、強い技・必殺(7)はコマが少ない。クールダウン中のコマは暗くなる
- ステータス6軸：HP・**こうげき**・**ぼうぎょ**・**すばやさ**・**きゅうしょ**（クリ率）・**こんじょう**（状態異常/回復/逆転）＋属性（ポケモン風のRPG用語）
- **種族値スケール**：絵の描き込み量＋乱数で合計値が 0.88〜1.12 倍（こうげき/ぼうぎょ/すばやさ 合計 79〜101、HP 50〜118）。**尖らせて**振るので「型」がハッキリ出る（こうげき型／がんじょう型／スピード型／バランス型）。理不尽にならない範囲
- 属性判定は色相だけでなく**明るさ・彩度**も見る（くらい絵・えんぴつの絵 → 闇）
- 止まったあとの「きめ」：かすり(×0.6, ~12%) / ふつう(×1) / クリティカル(×1.75, きゅうしょ依存 6〜34%)。**通常わざは相手の最大HPの55%まで**（乱数で一撃死しない）
- スカ ~10%。7コマ＝必殺（≈4%/ターン、約2バトルに1回）＋**成功判定あり**（失敗→通常の強攻撃に落ちる）。ゲージ制なし
- 技は約90：共通＋属性3段階×5＋特殊（形/部位/雰囲気/装飾/持ち物ごと）＋治療・補助。威力レンジは ☆1 6〜18／☆2 20〜28／☆3 32〜46。**絵の特徴タグ**で技セットを割り振り（**5〜8個・描き込みが多いほど多い**）
- 状態異常14種＋**治療手段**（技セットに必ず1つ治療系が入る）
- 強い技はクールダウン（出たあと1〜2ターン、リールから外れる）
- 属性相性 火→木→水（×1.4／×0.8）。雷・闇は状態異常特化。**無属性の技（たいあたり等）は相性なし・常にふつう**（分かりやすさ優先）
- 報酬：ステータス強化／属性わざ進化／新わざ習得。バトル長の中央値 約8ターン（最大15前後、サドンデス t12）

## 展示運用（予定）

- 会場PCで `npm run build` → `dist/` をローカル配信、ブラウザを全画面 Kiosk モード。
- カメラは固定スタンド。ネットが切れてもコア機能はすべて動く。
- 公開用は Cloudflare Pages / Vercel。
